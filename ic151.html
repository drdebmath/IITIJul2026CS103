Before coding

Set up the lab computer safely.

Check off each step as you complete it. This checklist is stored only in a first-party cookie in this browser.

Submission workflow

Join GitHub Classroom correctly.

Your official email and roll-number identity are used to match the repository to the class roster.

  1. 01
    Open the assignment link

    Use the link shared by the instructor or TA, while signed in to your official Google account.

  2. 02
    Create or sign in to GitHub

    Choose “Continue with Google” and use the official institute email, not a personal address.

  3. 03
    Use a recognizable username

    Your GitHub username must include your roll number. Complete any verification puzzle carefully.

  4. 04
    Authorize Classroom

    Allow GitHub Classroom access, then select your roll number from the roster.

  5. 05
    Check the roster match

    If the roll number is missing—or you selected the wrong one—contact the TA or instructor immediately.

  6. 06
    Accept and open the repository

    Accept the assignment, wait for repository creation, and open the blue repository link.

Edit and submit

Change only hello.cpp.

  1. Open hello.cpp in the assignment repository.
  2. Select the pencil icon labeled “Edit this file”.
  3. Make the changes described in the assignment.
  4. Scroll down and enter a clear commit message, for example Edited hello.cpp for assignment.
  5. Select “Commit changes”. Do not create or upload extra files.

Testing and resubmitting

Read the test result.

✓
Green tick

The automated checks passed.

×
Red cross

A test failed. Edit hello.cpp, commit again, and repeat until it passes.

Current lab note: automated GitHub Classroom tests may be unavailable during the introductory session. Follow the instructor or TA’s live direction.

Run before committing

Compile locally with g++.

Local testing gives faster feedback and makes compiler errors easier to understand.

Ubuntu terminal
mkdir -p ~/yourfirstname
cp hello.cpp ~/yourfirstname/
cd ~/yourfirstname
g++ hello.cpp -o hello
./hello
Windows terminal
g++ hello.cpp -o hello.exe
hello.exe

Before leaving

Leave no account behind.

  • Log out of Gmail and GitHub.
  • Confirm that the browser saved no passwords.
  • Remember your passwords for the next lab.
  • Ask a TA when blocked; help nearby classmates after completing your own setup.
  • Expect a second assignment during the lab and follow the same workflow.
