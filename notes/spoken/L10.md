So you get a value from somewhere - where are we getting the value in this program? It does not make room by replacing an earlier element. +} The only choice you have with an array is to throw a value away or replace one you already have.

## 24. Summary: dimensions, size, and storage
Status: taught

What I want you to take away from today's lecture is how a vector of vectors is laid out, and how it differs from a two-dimensional array. A vector of vectors first creates a vector of rows, and the address of the vector of rows is different from the address of the first row.

You also have to remember that the size of an `int` is 4 bytes. So if `a[0]` is at address 1000, then `a[1]` is at 1004 and `a[2]` is at 1008. That is how the offsets add up, and that is how you reach the memory blocks. This we already did.

So, the summary: each row and each column has its own index - don't mix them. A vector resizes automatically: you can increase its size dynamically by pushing back elements. {+ The vector object itself is an ordinary local variable, and it owns a separately allocated block where the elements live. +} `size` is the function that tells you how many elements are in it. And once you change the size past the capacity, the address changes - {+ the address of the elements, that is. The elements move to a new block, so any pointers or references into the old one become invalid, but the vector object itself stays where it is: `&v` does not change, only `&v[0]` does. +}
