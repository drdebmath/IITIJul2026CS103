Course roadmap

From first principles to real programs.

Nine connected modules move from C++ fundamentals to practical systems, with algorithms taught as applications of the structures they operate on.

Phase 01 · Foundations

Before mid-semester

  1. 01

    Programming & Problem Solving

    • Algorithms, decomposition, and testing
    • The C++ toolchain and a first program
  2. 02

    Types, Expressions & Program State

    • Types, representations, conversions, and constants
    • Expressions, scope, storage duration, and linkage
  3. 03

    Decisions & Iteration

    • Boolean conditions and safe branching
    • while, do-while, and input validation
    • for, nested loops, invariants, and boundaries
  4. 04

    Functions & Recursive Decomposition

    • Contracts, calls, parameters, and return values
    • References, overloading, and decomposition
    • Call stacks, base cases, and recursive problem solving
  5. 05

    Sequences, Text & Array Algorithms

    • Fixed arrays, traversal, and indexed state
    • Matrices and dynamically sized vectors
    • std::string, input, validation, and C-string reference
Phase 02 · Application

After mid-semester

  1. 06

    Records, Pointers & Memory

    • Structures, addresses, pointers, and indirection
    • Dynamic allocation, ownership, and memory safety
  2. 07

    Linear & Tree Data Structures

    • Linked lists as a dynamic-memory application
    • Stacks, queues, search, and elementary sorting
    • Recursive decomposition for structural algorithms
    • Binary search trees, heaps, merge sort, and their invariants
  3. 08

    Object Design & Value Semantics

    • Classes, invariants, constructors, copying, and operators
    • Friend access and inheritance foundations
  4. 09

    Inheritance, Polymorphism & Applied Systems

    • Substitutability, virtual dispatch, and factories
    • Polymorphic containers and object graphs
    • Domain models, search, sorting, and route planning
    • Recursive array, tree, matrix, and object applications
